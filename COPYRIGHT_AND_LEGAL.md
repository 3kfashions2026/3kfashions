## ❌ What You CANNOT Do (Illegal/Unsafe)

### 1. Trademark Violations
- ❌ Use Nike/Adidas/brand logos without permission
- ❌ Use brand name as your main brand
- ❌ Claim to be official store
- ❌ Use copyrighted logos

**Safe Alternative**: Use generic brand references
```
✓ "Running shoes from top brands"
✓ "Premium sneakers"
❌ "Nike Air Max Sneakers" (too specific)
```

### 2. Copyright Violations
- ❌ Copy product descriptions word-for-word
- ❌ Use photos directly from retail sites
- ❌ Steal content from competitors
- ❌ Reproduce copyrighted material

**Safe Alternative**: Use your own words
```
✓ "Comfortable, lightweight running shoe"
❌ [Copied from Nike website]
```

### 3. Misleading Claims
- ❌ "Official Nike Store" (false claim)
- ❌ "Buy directly from manufacturer" (false claim)
- ❌ Hide affiliate links
- ❌ Fake reviews

**Safe Alternative**: Be transparent
```
✓ "Curated affiliate platform"
✓ "We earn commission"
✓ Genuine reviews only
```

### 4. Fake Reviews
- ❌ Write fake positive reviews
- ❌ Pay for fake reviews
- ❌ Delete negative reviews
- ❌ Boost reviews artificially

**Safe Alternative**: Real reviews
```
✓ "Great quality, lasted 2 years"
✓ "Not for wide feet"
✓ Honest pros and cons
```

## 🛍️ Affiliate Network Rules

### Amazon Associates
- ✓ Can link to any product
- ✓ Can use affiliate links
- ✓ Must disclose: "As an Amazon Associate..."
- ❌ Cannot claim to be Amazon
- ❌ Cannot guarantee lowest price
- Link format: `amazon.in/?tag=YOUR_TAG`

### Myntra
- ✓ Can use affiliate links
- ✓ Can recommend products
- ❌ Cannot misrepresent Myntra
- ❌ Cannot claim to be official
- Link format: `myntra.com/?utm_source=yoursite`

### Flipkart
- ✓ Can use affiliate links
- ✓ Can promote products
- ❌ Cannot claim direct sales
- ❌ Cannot imitate Flipkart
- Link format: `flipkart.com/...via=...`

### Meesho
- ✓ Can share affiliate links
- ✓ Can earn commission
- ❌ Cannot claim inventory
- ❌ Cannot resell directly

## 🎓 Safe vs Unsafe Examples

### Example 1: Product Description

**UNSAFE:**
```
"Nike Air Max 90 Running Shoe - Authentic, official Nike quality.
Lightweight, breathable mesh upper with responsive cushioning.
Perfect for running or casual wear. Limited time offer!"
```
❌ Claims authenticity
❌ Too specific brand reference
❌ Might violate Nike trademark

**SAFE:**
```
"Lightweight Running Shoe - Mesh upper with cushioned sole.
Great for everyday wear or exercise. Breathable comfort design.
Available at multiple retailers."
```
✓ Generic description
✓ Feature-focused
✓ No brand claims
✓ Honest

### Example 2: Affiliate Disclosure

**UNSAFE:**
```
[Hidden link in "click here"]
No disclosure
```
❌ Hidden link
❌ No transparency

**SAFE:**
```
"BUY NOW*"
*Affiliate link - We earn commission at no extra cost to you
```
✓ Clear disclosure
✓ Visible link
✓ Transparent

## 📞 If You Get Cease & Desist

1. **STOP** immediately - remove offending content
2. **SAVE** all communication
3. **CONSULT** a lawyer
4. **RESPOND** within timeframe (usually 30 days)
5. **COMPLY** with takedown request

Most issues can be resolved by:
- Removing copyrighted content
- Removing trademark references
- Adding proper disclaimer
- Removing fake reviews
